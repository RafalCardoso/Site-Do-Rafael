# Portfólio Rafael Cardoso — Desenvolvedor Web (versão em português)

Portfólio responsivo de página única, com estética premium e futurista, desenvolvido com HTML, CSS e JavaScript puro. Não requer instalação ou chave de API.

## Visualizar

Abra `index.html` no navegador. Para desenvolvimento, também é possível abrir a pasta no VS Code e utilizar a extensão Live Server.

## Publicar na Vercel

1. Entre em https://vercel.com/new e faça login.
2. Importe um repositório GitHub que contenha os arquivos desta pasta **na raiz**.
3. Em **Framework Preset**, escolha **Other**; deixe o comando de build vazio.
4. Clique em **Deploy**.

Alternativa: publicar no Netlify arrastando a pasta para https://app.netlify.com/drop.

- **Cores e espaçamentos:** edite as variáveis no início de `styles.css`.
- **Comportamentos:** edite `script.js`.
- **WhatsApp:** procure no `index.html` por `5564992529594` e substitua caso troque de número. O formato é `55` + DDD + número. O número atual aponta para **(64) 99252-9594**.
- **Portfólio:** os três exemplos de interface são **conceitos visuais**. Substitua-os por seus projetos reais quando quiser.
- **Domínio:** se tiver domínio próprio, configure-o na plataforma de hospedagem.

As telas de exemplo são conceitos, não depoimentos ou trabalhos de clientes. Para usar em produção, substitua por seu conteúdo real e ajuste dados como domínio, política de privacidade ou outras exigências do seu negócio quando aplicáveis.
